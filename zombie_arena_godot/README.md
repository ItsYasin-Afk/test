# Zombie Arena (Godot 4.4.1)

یک بازی بقا در میدان زامبی برای اندروید؛ بدون تصویر یا فایل جانبی ساخته شده و همهٔ گرافیک‌ها با رسم برداری خود Godot نمایش داده می‌شوند. پروژه برای Godot 4.4.1 آماده شده است.

## بازی
- بازمانده را با جوی‌استیک لمسی سمت چپ حرکت دهید.
- دکمهٔ بزرگ **SHOOT** را نگه دارید تا خودکار به نزدیک‌ترین زامبی شلیک شود.
- در نسخهٔ دسکتاپ با WASD یا کلیدهای جهت حرکت کنید و Space یا نگه‌داشتن کلیک ماوس شلیک می‌کند.
- زامبی‌ها به‌مرور سریع‌تر و پرتعدادتر می‌شوند؛ زامبی‌های درشت چند ضربه لازم دارند. امتیاز، زمان، نوار سلامتی و صفحهٔ شروع دوباره نمایش داده می‌شود.

## ساخت APK با GitHub Actions
۱. ZIP را باز کنید و **محتویات داخل آن** را به ریشهٔ یک مخزن GitHub بارگذاری کنید؛ فایل‌های ریشه و پوشهٔ مخفی `.github` باید حفظ شوند. بهتر است از Git استفاده کنید، چون بارگذاری وب GitHub ممکن است پوشه‌های نقطه‌دار مانند `.github` را نادیده بگیرد:

```sh
git init
git add .
git commit -m "Add Zombie Arena game"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

۲. در مخزن GitHub وارد **Actions** شوید و اجرای **Build Android APK** را باز کنید (یا از **Run workflow** آن را دستی اجرا کنید).
۳. پس از موفقیت، از بخش **Artifacts**، فایل `zombie-arena-debug-apk` را دانلود و ZIP آرتیفکت را باز کنید؛ فایل داخل آن `zombie_arena.apk` است.
۴. APK را به گوشی منتقل و نصب کنید. ممکن است لازم باشد برای برنامهٔ نصب‌کننده اجازهٔ نصب از منابع ناشناس را فعال کنید.

این خروجی APK دیباگ و برای نصب/آزمایش است؛ امضای انتشار Google Play نیست و برای انتشار فروشگاهی آماده نشده است. اجرای CI یا ساخت APK در این محیط انجام نشده و موفقیت نهایی تا اجرای واقعی workflow تضمین‌شده نیست. هیچ کلید یا رمز محرمانه‌ای در پروژه قرار ندارد.

## اجرای محلی
پروژه را در Godot 4.4.1 باز کنید و `scenes/Main.tscn` یا پروژه را اجرا کنید. ساخت Android محلی به export templates و Android SDK/JDK سازگار نیاز دارد.
